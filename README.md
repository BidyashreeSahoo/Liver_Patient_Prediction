# Liver Patient Prediction

## Project Overview
The Liver Patient Prediction project uses Machine Learning techniques to predict whether a person may have liver disease based on medical attributes. The project includes data analysis, data preprocessing, model training, and model evaluation.

## Problem Statement
The main objective of this project is to analyze patient data and build a Machine Learning classification model to predict liver disease.

## Dataset
The dataset contains patient information, including:
- Age
- Gender
- Total Bilirubin
- Direct Bilirubin
- Alkaline Phosphotase
- Alamine Aminotransferase
- Aspartate Aminotransferase
- Total Proteins
- Albumin
- Albumin and Globulin Ratio
- Target

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Machine Learning

## Project Workflow
1. Data Loading
2. Exploratory Data Analysis (EDA)
3. Data Cleaning and Preprocessing
4. Handling Missing Values
5. Feature Engineering
6. Model Training
7. Model Evaluation
8. Liver Disease Prediction

## Machine Learning Models
The project explores classification algorithms such as:
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- Gradient Boosting
- Support Vector Machine (SVM)
- Naive Bayes
- XGBoost

## Project Files
- `Liver_Patient.csv`
- `Liver_Patient_Prediction.ipynb` 
## Conclusion
This project demonstrates how Machine Learning can be used to analyze patient data and predict possible liver disease. It provides practical experience in data preprocessing, classification, and model evaluation.

**Note:** This project is for educational purposes only and should not be used as a substitute for professional medical diagnosis.
